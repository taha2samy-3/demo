Four flame graph types

On-CPU, off-CPU, allocations, and IPC-coloured — rendered side by side for tls-demo (Go, mutual TLS between service-a and service-b).

These are sample stacks, not a live capture. They're shaped to match what this app actually does — Go runtime, crypto/tls handshakes, ECDSA cert verification, JSON payload rendering — so the graphs read realistically, but the numbers are invented. Each panel has a How to capture real data section with the commands that produce the real thing. Replace the folded-stack arrays in the page source and the graphs redraw from your own data.
